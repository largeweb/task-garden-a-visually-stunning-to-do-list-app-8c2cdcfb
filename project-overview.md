# Project Overview

Project Name: "Task Garden" - A visually stunning To-Do List App

Description: Transform your to-do list into a beautiful, growing garden. Each task is represented by a plant. Complete tasks to "grow" your garden! This app prioritizes visual appeal and provides a relaxing way to manage your tasks.

Features:
*   Task = Plant: Each to-do item is visualized as a unique plant in your garden.
*   Completion = Growth: Complete tasks to see your plants grow and flourish.
*   Customizable Garden: Choose from various plant types, garden themes, and backgrounds.
*   Relaxing UI: Simple, intuitive design to promote calm focus.
*   Task Priority = Plant Type: Important task? Make it a vibrant sunflower!

Technology Stack:
*   Cloudflare next-on-pages framework (NextJS) for the web application.
